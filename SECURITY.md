# Security Policy

## Supported versions

Only the latest release on the default branch receives security fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository
(Security tab → "Report a vulnerability"). Please do not open public
issues for suspected security problems.

Include reproduction steps, the affected endpoint or file, and the
earliest affected commit where possible. Reports are acknowledged as
soon as possible; coordinated disclosure is preferred.

For issues specific to the live `*.0xbot.org` services rather than this
codebase, use the same channel so they reach the operators directly.
